## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup


1. clonar el repositorio
2. ejecutar 
  ```npm install```
3. Tener NEst CLI instalado
```npm i -g @nestjs/cli```


4. levantr la base de datos 
```docker-compose up -d```


```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
